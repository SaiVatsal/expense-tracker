# SYLVAN WEALTH // Personal & Business Expense Tracker

A comprehensive financial ledger and multi-account treasury management application built with React, Vite, Tailwind CSS, and Zustand, simulating a Firebase Firestore backend.

## 🌿 Key Features
- **Multi-Account Treasury View**: Monitor Checking, High-Yield Treasury, and Venture Credit accounts in unified or segmented balances.
- **Category Budget & Live Overspend Alerts**: Real-time progress bars with dynamic warning banners whenever a spending ceiling is breached.
- **Itemized Fiscal Ledger**: Filterable income and expense history with inline record deletion and fast search.
- **Recurring Commitment Scheduler**: Monthly automated expense forecasting for SaaS, cloud infrastructure, and retainers.
- **CSV Ledger Export**: Instant CSV financial data download for tax reporting and accounting audits.
- **Monthly Digest Notification**: Automated summary report trigger simulation.

## 🚀 Quickstart
```bash
npm install
npm run dev
```
